# 03. AI Fundamentals

Learn to frame AI problems, understand learning from data, evaluate generalization, distinguish models from workflows and agents, and identify harms before implementation. This module supplies the conceptual tests used by every later architecture decision.

## Before you begin

Complete [Module 02](../02-digital-literacy-and-cloud/index.md), or be comfortable with files, structured data, services, and basic security boundaries. No calculus or paid AI service is required.

## Suggested artifact

Write an AI suitability memo for one real process. Define the target, baseline, data boundary, evaluation split, error costs, non-AI alternative, human authority, and a clear stop condition.
