# Instructional Image Sources

The raster illustrations in this directory were generated specifically for this repository with OpenAI image generation on 2026-08-11. They contain no third-party logos or copied interface designs. Their purpose is educational: each image has adjacent prose and descriptive alternative text so it is not the sole source of information.

## AI automation course system

`ai-automation-course-system.png` presents an end-to-end system boundary: governed documents and structured data, retrieval, a model, narrow tools, workflow control, human approval, downstream systems, tests, and monitoring.

Prompt intent: a bright, restrained technical cutaway with a clear left-to-right flow; no embedded words, logos, humanoid robots, decorative gradients, or autonomous action that bypasses review.

## Grounded retrieval

`rag-grounded-retrieval.png` presents source governance, metadata-rich chunks, lexical and vector retrieval, access filtering, cited support, and abstention when evidence is insufficient.

Prompt intent: a precise educational pipeline with trusted, uncertain, and blocked paths; no embedded words, logos, magical effects, or implication that retrieval automatically makes an answer true.

## Human oversight

`human-oversight-control.png` presents risk-based routing, monitored low-impact execution, informed human review for consequential actions, blocked prohibited actions, durable state, and audit records.

Prompt intent: a professional operational review environment where a human has evidence and meaningful choices; no ceremonial approval, stock-office styling, or autonomous high-impact execution.

## Evaluation release dashboard

`evaluation-release-dashboard.svg` is not generated by an image model. It is deterministically rendered by `scripts/generate_evaluation_chart.py` from the synthetic data in `content/assets/data/evaluation-release-results.csv`. Run the generator after changing the data, or use `--check` to verify that the SVG is current.
