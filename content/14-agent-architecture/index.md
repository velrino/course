# 14. Agent Architecture

Define agent system boundaries before selecting a framework. The module covers models, tools, planning, control loops, context, memory, retrieval, multi-agent tradeoffs, threat models, evaluation, and meaningful human authority.

## Before you begin

Complete the design and algorithm modules through [Module 13](../13-advanced-n8n-and-integrations/index.md). Bring a deterministic workflow baseline so agentic complexity must earn its place.
