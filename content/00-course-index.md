# Free AI Automation and Agent Engineering Curriculum

This curriculum turns the two reference syllabi into an independent, free-first course. It does not reproduce either provider's lessons. Instead, it uses the topic coverage as a roadmap and teaches each subject through public documentation, standards, research papers, and original exercises.

## How to start

1. Read [Course orientation and study plan](00-course-orientation-and-study-plan/01-how-to-use-this-course.md).
2. Create a learning journal using the template in [Assessment and evidence](00-course-orientation-and-study-plan/05-assessment-and-evidence.md).
3. Complete modules in order unless the competency map gives you a reason to skip ahead.
4. Build at least three capstones, including one with human approval before any consequential action.
