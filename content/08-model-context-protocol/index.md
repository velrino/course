# 08. Model Context Protocol

Understand MCP hosts, clients, servers, transports, capabilities, tools, resources, and prompts. Then design, implement, inspect, connect, secure, and govern a typed local server.

## Before you begin

Complete [Module 06](../06-web-apis-and-webhooks/index.md); [Module 07](../07-docker-and-infrastructure/index.md) is useful for isolated deployment. You should be able to read JSON schemas and run a local command.

## Lessons

1. [Understand MCP Architecture and Lifecycle](01-understand-mcp-architecture-and-lifecycle.md)
2. [Design Tools, Resources, and Prompts](02-design-tools-resources-and-prompts.md)
3. [Build a Local MCP Server](03-build-a-local-mcp-server.md)
4. [Test, Inspect, and Connect MCP Servers](04-test-inspect-and-connect-mcp-servers.md)
5. [Secure and Govern MCP Integrations](05-secure-and-govern-mcp-integrations.md)

## Suggested artifact

Build a local read-mostly MCP server with narrow schemas, deterministic fixtures, protocol tests, Inspector evidence, an allowlist, a threat model, and an approval boundary for any side effect.

[MCP Task Server](https://github.com/velrino/course/tree/master/labs/mcp-task-server) provides a small server, fixtures, and tests for the module's tool-contract work.
