# 29. Node.js for Automation

Build reliable JavaScript automations using the Node.js runtime, explicit project boundaries, safe files and CLIs, schema validation, HTTP APIs, webhooks, retries, asynchronous concurrency, queues, idempotency, tests, and structured logging.

Deliver a Node.js automation with ESM boundaries, validated CLI and webhook inputs, safe file writes, abortable HTTP calls, bounded concurrency, an idempotent queue, structured logs, deterministic tests, and a documented failure-recovery demonstration.
