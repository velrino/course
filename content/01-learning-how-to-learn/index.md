# 01. Learning How to Learn

Build a study system that produces durable recall and transferable engineering skill. The module combines knowledge mapping, retrieval, spacing, interleaving, feedback, and debugging into a weekly control loop.

## Before you begin

Complete the [orientation module](../00-course-orientation-and-study-plan/index.md), especially its assessment and evidence rules. Bring one real skill you need to learn so the methods operate on meaningful material.

## Lessons

1. [Build an Evidence-Based Study System](01-build-an-evidence-based-study-system.md)
2. [Turn a Syllabus into a Knowledge Map](02-turn-a-syllabus-into-a-knowledge-map.md)
3. [Retrieve, Space, and Interleave](03-retrieve-space-and-interleave.md)
4. [Practice, Feedback, and Debugging](04-practice-feedback-and-debugging.md)
5. [Run a Sustainable Weekly Learning Loop](05-run-a-sustainable-weekly-learning-loop.md)

## Suggested artifact

Run a two-week learning experiment with a knowledge map, retrieval prompts, spaced review dates, error log, and before/after evidence of a transfer task.
