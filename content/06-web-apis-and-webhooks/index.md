# 06. Web, APIs, and Webhooks

Trace a web request from name resolution through HTTP and application behavior, then design and consume APIs with explicit contracts. The module closes with authenticated, replay-safe webhook handling.

## Before you begin

Complete [Module 02](../02-digital-literacy-and-cloud/index.md) and preferably [Module 05](../05-prompt-context-and-loop-engineering/index.md). You should be able to use a terminal and read JSON.

## Lessons

1. [Understand the Web Request Path](01-understand-the-web-request-path.md)
2. [Read and Send HTTP Messages](02-read-and-send-http-messages.md)
3. [Design and Consume REST APIs](03-design-and-consume-rest-apis.md)
4. [Describe APIs with OpenAPI](04-describe-apis-with-openapi.md)
5. [Receive Webhooks Reliably and Securely](05-receive-webhooks-reliably-and-securely.md)

## Suggested artifact

Create a local API client and webhook receiver with an OpenAPI contract, timeouts, status-aware retries, signature verification, replay protection, structured logs, and integration tests.
