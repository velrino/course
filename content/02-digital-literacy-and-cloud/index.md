# 02. Digital Literacy and Cloud

Develop the operating-system, shell, Git, data-format, network, database, cloud, and security vocabulary needed to reason about modern automations. The goal is not memorization; it is the ability to trace where data moves and where failures or risks enter.

## Before you begin

Use the review loop from [Module 01](../01-learning-how-to-learn/index.md). You need a computer on which you can create files and run a terminal; the lessons provide the remaining setup.

## Lessons

1. [Navigate Computers, Files, and the Internet](01-navigate-computers-files-and-the-internet.md)
2. [Use the Command Line and Git](02-use-the-command-line-and-git.md)
3. [Read Data Formats, Databases, and Integrations](03-read-data-formats-databases-and-integrations.md)
4. [Build a Cloud Mental Model](04-build-a-cloud-mental-model.md)
5. [Protect Accounts, Data, and Decisions](05-protect-accounts-data-and-decisions.md)

## Suggested artifact

Create a version-controlled systems notebook containing a filesystem exercise, a small JSON/CSV transformation, a request-path diagram, a cloud responsibility map, and a personal security checklist.

## Continue

Use this systems vocabulary to distinguish suitable and unsuitable problems in [Module 03: AI Fundamentals](../03-ai-fundamentals/index.md).
