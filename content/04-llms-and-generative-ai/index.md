# 04. LLMs and Generative AI

Build a working mental model of tokens, embeddings, next-token prediction, Transformers, training, alignment, inference, and decoding. You will also run a small local model and measure behavior instead of relying on product impressions.

## Before you begin

Complete [Module 03](../03-ai-fundamentals/index.md). A machine that cannot run a local model can still complete the conceptual work and use the documented deterministic alternatives.

## Suggested artifact

Produce a reproducible local-model experiment with model identity, hardware notes, fixed prompts, decoding settings, latency, output-quality rubric, failure examples, and a short limitations report.
