# Forty-Week Study Plan

## Objectives

Turn the curriculum into a sustainable schedule with explicit review and project weeks.

## Recommended schedule

The plan below targets approximately 360 to 400 hours. It is a planning aid, not a certification claim.

| Weeks | Modules and milestone |
|---:|---|
| 1-2 | 01-02: learning practice and digital foundations |
| 3-5 | 03-04: AI, machine learning, LLMs, and generative AI |
| 6-7 | 05: prompt, context, harnesses, and loops |
| 8-10 | 06-08: HTTP, APIs, Docker, infrastructure, and MCP |
| 11-13 | 09-10: process discovery, prioritization, use-case design, and storyboards |
| 14-16 | 11-12: algorithms and n8n fundamentals |
| 17-19 | 13-14: advanced n8n integrations and agent architecture |
| 20-22 | 15: retrieval, knowledge sources, and memory |
| 23-25 | 16-17: human approval, multimodality, security, privacy, and LGPD |
| 26-28 | 18-19: evaluation, monitoring, optimization, and multi-agent systems |
| 29-31 | 20-21: Python automation and relational databases; add 29 as the Node.js automation specialization |
| 32-34 | 22: analysis, statistics, and visualization |
| 35-36 | 23: LangChain and LangGraph |
| 37 | 24: CrewAI |
| 38 | 25: fine-tuning and adaptation |
| 39 | 26-27: governance, risk, delivery, and adoption |
| 40 | 28: capstone review and portfolio presentation |

## Review gates

At the end of weeks 10, 19, 28, and 40, stop adding features. Run a review gate:

1. Re-run artifacts from a clean environment.
2. Complete a closed-notes concept check.
3. Test one misuse case and one infrastructure failure.
4. Update the competency map.
5. Remove or revise any claim that your evidence does not support.

If a gate fails, schedule remediation before continuing. The purpose is durable competence, not calendar compliance.

## Faster and slower tracks

For a 20-week track, combine adjacent weeks but preserve all four review gates. For a 60-week track, keep the module order and use the additional time for coding practice and more representative evaluation datasets. Do not compress security, evaluation, or governance simply because those modules appear later.

## Practice

Copy the table into your learning journal. Add actual dates, weekly time limits, and four review appointments. Mark any week affected by work or care responsibilities and redistribute the load now rather than relying on future catch-up.

## Completion criteria

- Every module has a planned week.
- Four review gates are on your calendar.
- The schedule includes buffer time and respects your weekly limit.
- You know what evidence determines whether you advance after a gate.
