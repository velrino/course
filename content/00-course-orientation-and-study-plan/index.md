# 00. Course Orientation and Study Plan

Set up a free-first, evidence-driven learning system before choosing tools. This module defines the course contract, competency map, pace, environment, assessment method, and source policy used throughout the curriculum.

## Before you begin

No technical prerequisite is required. Reserve a repeatable weekly study window and create a local directory where you can keep a learning journal and project evidence.
