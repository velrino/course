# 19. Multi-Agent Orchestration

Decide when multiple agents are justified, then define their contracts, context, state, routing, parallel work, synthesis, verification, reliability, security, and governance. Every design must be compared with a simpler baseline.

## Before you begin

Complete [Modules 14-18](../14-agent-architecture/index.md). Bring an evaluated single-agent or deterministic implementation and a task whose separable roles can be measured independently.

## Suggested artifact

Build a bounded orchestration with typed handoffs, minimum context, traceable routing, deterministic synthesis rules, an independent verifier, budgets, adversarial tests, and a measured comparison against the simpler baseline.
